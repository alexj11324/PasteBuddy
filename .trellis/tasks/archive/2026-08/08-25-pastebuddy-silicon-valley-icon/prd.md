# PasteBuddy Silicon Valley app icon

## Goal

为 PasteBuddy 设计一组克制、清晰、具有硅谷效率工具气质的全新候选图标，让用户直接比较视觉效果后选定方向；候选应表达“收集、整理、再次粘贴”的核心工作，并提供真正透明背景的母版。

## Confirmed Facts

- PasteBuddy 是面向 macOS、iOS 与 iPadOS 的 local-first 剪贴板管理器，核心价值是保存、组织、搜索并重新使用剪贴板内容。
- 当前 AppIcon 是白色圆角底板上的蓝紫渐变抽象 `P`，源文件 `Support/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` 为 1024 x 1024 RGB PNG，不含 alpha 通道。
- 本轮只生成独立候选稿，不覆盖现有 AppIcon，不修改产品代码，也不视为生产图标交付。
- 最终生产交付若进入 Icon Composer，必须将图层重建为可独立编辑的 SVG；生成式 PNG 只用于概念选择与视觉方向验证。
- 用户不喜欢当前图标，不要求保留或放弃现有 `P`；本轮同时探索两类方向，以成图效果作为选择依据。

## Requirements

- 图标定义：一枚代表 PasteBuddy “收集并再次取用内容”的现代生产力工具符号。
- 采用一个主轮廓、清晰负空间和单一深度语言；避免文字、徽章、UI 截图、随机渐变、霓虹光晕与通用 AI 星芒。
- 在 24、32、48、64、128 与 1024 px 保持可辨识；缩小后仍能与普通剪贴板图标和单字母 `P` 图标区分。
- 候选 PNG 必须为真实透明背景并保留 alpha，不预烘焙系统圆角蒙版或外部投影。
- 视觉气质应克制、精密、友好，接近成熟的开发者工具/生产力初创品牌，而不是企业办公套件或卡通消费应用。
- 一次生成四枚构图明显不同的候选，每枚独立生成，避免把多个小图拼在同一张概念板上。
- 候选中包含字母延续与非字母符号，但都不能沿用当前蓝紫渐变 `P` 的具体造型。

## Direction Options

1. **Folded P**：由两张重叠卡片和一次折返构成新的几何 `P`，用负空间暗示 copy → paste；保留字母但彻底改变当前造型。
2. **Pocket Stack**：一个开口容器承接两张内容卡片，表现“随手收集、快速取回”；产品语义最直接。
3. **Paste Loop**：一条连续带状路径完成输入、暂存与输出循环；更抽象，更接近开发者工具或基础设施品牌。
4. **Snap Tiles**：两枚错位方片通过一个精确咬合的负空间连接，表现复制与复用；轮廓最简洁，小尺寸识别潜力最高。

## Acceptance Criteria

- [x] 使用内置 image generation 工具分别生成四枚 1:1、无文字、真实透明背景的候选 PNG。
- [x] 四枚候选覆盖 `Folded P`、`Pocket Stack`、`Paste Loop` 与 `Snap Tiles`，结构差异足以让用户直接比较，而不是只有配色变化。
- [x] 每枚候选在透明棋盘格、浅色与深色背景上边缘干净，没有白底残留。
- [x] 每枚候选提供 24、32、48 与 64 px 缩略检查；主轮廓不依赖微小细节才能成立。
- [x] 四枚图像保存到仓库内独立的候选目录，不覆盖 `Support/Assets.xcassets/AppIcon.appiconset` 或 `Support/AppIcon.icns`。
- [x] 交付时同时展示四枚候选，并报告文件路径、各自最终生成提示词、透明度检查和小尺寸检查结果。

## Out of Scope

- 本轮不替换生产 AppIcon，不更新 Xcode asset catalog，不打包或发布应用。
- 本轮不把生成式位图冒充 Icon Composer 最终分层矢量资产。
- 本轮不要求从四枚候选中自动替用户选定最终方案，也不继续生成二轮变体；用户选定方向后另行迭代。
- 未经用户确认，不扩展为完整品牌手册、字标、营销插画、Icon Composer 分层矢量或多平台导出套件。

## Risks and Deferred Items

- 生成式位图可能出现边缘或几何不够精确的问题；本轮用于方向选择，选定后再以矢量方式重建。
- Apple App Store 的最终图标通常不以透明背景直接提交；透明输出是为了保留可编辑性和方便后续分层组合，生产导出规则留到选定方案后处理。
